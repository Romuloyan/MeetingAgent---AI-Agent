# Google Colab notebooks

This folder contains the Colab-side code used by the MeetingAgent workflow.

The project is split into three stages:

1. **Notebook 1 — transcription**  
   File: `01_transcription_faster_whisper_colab.py`  
   Runs in Google Colab, reads audio/video files from Google Drive, transcribes them with `faster-whisper`, and exports timestamped transcripts, SRT subtitles, DOCX files, JSON segments, and a ZIP package.

2. **Notebook 2 — speaker diarization**  
   File: `02_diarization_pyannote_one_click_colab.py`  
   Runs in Google Colab, reads the transcript JSON generated by Notebook 1, uses `pyannote.audio` to detect speakers, aligns speaker intervals with transcript segments, and exports speaker-labelled transcripts.

3. **Local MeetingAgent Streamlit app**  
   File: `../app.py`  
   Runs locally, allows manual speaker-name assignment, optional document upload, and Gemini-based draft minutes generation.

## Why these files are `.py` and not `.ipynb`

The code is stored as plain Python files so it is easy to review, version-control, copy into Colab cells, and improve over time.

Each file is written as a Colab-compatible script/cell. It can be pasted into a Colab notebook, or converted into `.ipynb` later.

## Privacy

The Colab notebooks are included, but real meeting recordings, transcripts, generated minutes, API keys, Hugging Face tokens, and ZIP exports are intentionally excluded from the repository.

## Required secrets

Notebook 2 requires a Hugging Face token with access to the pyannote model. During development this was stored in Colab Secrets as:

```text
TOKEN
```

Do not commit this token to the repository.
